1. Access requirements

The Fred Learning Review dashboard is restricted to users with the Admin role.

Granting Admin access to another user

  1. Ask the engineering team to update the user's record in the Seima Users registry.
  2. Once updated, the user will see the Fred Review button in the navigation bar on their next sign-in.

2. How learning works

Fred's learning system collects feedback from users to help admins improve response quality over time:

  1. User asks a question.
  2. Fred responds — thumbs-up / thumbs-down buttons appear below each response.
  3. User rates the response — the rating, question, and answer text are saved.
  4. Aggregation — ratings and question counts roll up so you can see them on this dashboard.
  5. Dynamic suggestions — the most frequently asked questions are shown to users as quick-start suggestion buttons in the chat.

Important: Fred does not currently use feedback to change its actual AI responses automatically. The learning data is informational — it helps admins identify gaps in Fred's knowledge so you can guide engineering to update the prompt, add FAQs, or refine behaviour.

3. Using the Review dashboard

The Fred Learning Review page (the screen you came from) gives you an at-a-glance view of:

  • Summary cards — total helpful / not-helpful ratings and overall satisfaction percentage.
  • Thumbs-Down Responses — the most recent answers users found unhelpful. Use these to identify where Fred is falling short.
  • Top Questions — the most frequently asked questions across all users. These drive the dynamic suggestion buttons in the chat.
  • Recent Feedback — a full feed of all feedback entries, filterable by Up / Down.

Click the Refresh button to reload the latest data.

Old feedback entries are removed automatically over time; you do not need to clean them up by hand.

4. Improving Fred's responses

When you see patterns in the thumbs-down feedback — for example, Fred consistently gives wrong answers about a specific product category, or misunderstands a type of question — you can ask the engineering team to update Fred's instructions.

What helps engineering act on feedback

The more concrete the example, the easier it is to fix. Helpful inputs include:

  • Specific corrections — "When asked about freestanding baths, always mention the weight capacity."
  • Common mistakes to avoid — "Never recommend discontinued products from the Heritage range."
  • FAQ-style answers — "If the user asks about warranty, explain that all Seima products carry a 25-year warranty on..."
  • Tone or formatting preferences — "Always respond in dot points when listing multiple products."

Tip: Concrete examples work best. "When comparing products, always include dimensions and price" is more actionable than "Be more helpful."

5. Operational changes

If you need to:

  • Remove or reword an entry in the Top Questions list,
  • Reset the feedback counters,
  • Delete a specific feedback record on request, or
  • Investigate why a particular response was given,

contact the engineering team. They have the tools to make these changes safely. Direct console access is restricted to ops; please do not attempt to bypass the dashboard.
